# 유엘이키우기

카페를 키우며 성경 읽기(쉬운 말 개역한글)·말씀 암송·오공완/오운완 사진 인증으로 달란트를 모으는 게임이에요.

## 아이폰 홈 화면에 추가하기
1. 사파리로 이 사이트 주소를 열어요.
2. 공유 버튼(네모에서 화살표가 위로 나온 모양)을 눌러요. 안 보이면 오른쪽 아래 … 을 먼저 눌러요.
3. 홈 화면에 추가 → 추가.

진행 기록과 인증 사진은 각자의 휴대폰 안에만 저장돼요. 하던 게임은 설정 › 저장 코드로 옮길 수 있어요.

성경 본문: 개역한글(대한성서공회, 1961). 화면에서는 요즘 잘 쓰지 않는 말을 쉬운 말로 바꿔 보여 주고, '원문'을 누르면 개역한글 그대로 볼 수 있어요.
